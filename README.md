# JavaScriptFundamentos03

Continuação dos estudos de JavaScript com foco em funções, Métodos de array, Objetos , JSON e introdução a Programação Orientção a Objetivo

## Objetivos 

Ao final deste projeto, O aluno devera ser capaz de:

* Criar e ultilizar funções
* Trabalhar com parãmetros, Argumentos e retornos;
* Ultilizar Arrow Functions
* Criar e Manipular Objetos;
* Trabalhar com array de objetos;
* Entender o uso de  this
* Converter objetos para JSON e JSON para objetos;
* Criar classe;
* Ultilizar "Contrutor";
* instanciar objetos e métodos;
* Compreender os conceitos iniciais de encapsulamento, Herança e polimorfismo;

## Como executar

Abra o terminal na pasta do projeto e execute;

```bash
    node nome-de-arquivo.js
```
